# Correlation-Analysis
Analyzing the association between life expectancy and per capita gross domestic product for the countries of the  world. 
This file shows histograms of life expectancy and GDP per capita and then a scatter plot combining both variables. 
Then we test correlation using the Pearson's and the Spearman's correlation tests. 
Then using the correlation statistics and critical values computed we can determine whether there is an association between life expectancy and per capita gross domestic product for the countries of the world. 
Because both of the test statistics were not 0 (closer to 0.7~0.8) there is indeed a strong positive correlation between the two variables.
